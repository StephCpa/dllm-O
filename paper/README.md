# ACL/ARR Working Manuscript

This directory is the ACL/ARR-format working copy of the decoding-policy
manuscript. It is the active submission-shaped source in this package.

## Build

```bash
make
```

The Makefile regenerates the audited manuscript-number macros and Figures 2--5
from the committed reports before running `latexmk`. `main.tex` uses the
official ACL review style and keeps the paper anonymous for ARR review.
`make distclean` removes the build outputs and the generated macros and
figures; a following `make` rebuilds everything.

Figure 1 is a manually reviewed schematic and is not regenerated by `make`.
After editing it, redraw it with:

```bash
python figures/fig1_overview.py
```

Figures 2--5 are drawn at ACL single-column width (3.1 in), so their text
prints at about 6--7 pt. Keep that width if you change them.

`REVISION_NOTES_20261001.md` lists the changes in the current revision and
the decisions still open for the authors.

## Submission constraints

- The current PDF keeps the main text within the ACL eight-page limit; references and the appendix begin after the main text.
- `Limitations` is a dedicated section, separate from `Discussion`, and follows the Conclusion so that it does not count toward the page limit.
- The AI Use Statement is retained as a separate disclosure section.
- The current copy is a working draft, not a venue-specific camera-ready package. Recheck the selected venue's current CFP, checklist, metadata, and artifact requirements before submission.
